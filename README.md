**MMT Pro: Smart Finance Tracker** **A full-stack personal finance dashboard bridging the gap between raw data and actionable financial insights.**

-----
### **Executive Summary**

**MMT Pro** is a cloud-synced financial management tool designed to provide a seamless user experience for tracking expenses and long-term savings goals. Built with a focus on **User Experience (UX)** and **Data Integrity**, it transforms static Google Sheets data into a dynamic, visual dashboard using Python and the Streamlit framework.

### **Strategic Features**

  * **Dynamic Budgeting Engine:** Empowers users to adjust monthly fiscal limits in real-time via a custom UI, instantly recalculating "Safe-to-Spend" margins and liquidity.
  * **Goal-Oriented Savings Logic:** Automates the calculation of monthly contributions required to hit long-term financial milestones, assisting in disciplined wealth building.
  * **Psychographic Spending Analysis:** Leverages a "Mood Insight" engine to visualize the emotional drivers behind purchases, providing a unique layer of behavioral finance tracking.
  * **Cloud-Native Architecture:** Securely integrated with **Google Cloud Platform (GCP)** via Service Accounts for real-time data persistence and multi-device access.

### **Tech Stack & Competencies**

  * **Data Orchestration:** Python (**Pandas**) for ETL processes, data cleaning, and column normalization.
  * **Visualization:** **Plotly Express** for interactive, responsive financial charting and trend analysis.
  * **Interface Design:** Custom **CSS/HTML injection** for a modern Glassmorphism UI, optimizing for high readability and professional aesthetics.
  * **Security & DevOps:** Managed environment variables (Streamlit Secrets) and `.gitignore` protocols to ensure API credential safety and industry-standard development practices.

### **Repository Structure**

  * **financeapp.py:** The core application logic, state management, and UI rendering.
  * **requirements.txt:** Managed dependencies ensuring a reproducible production environment.
  * **gitignore:** Security layer preventing the exposure of sensitive service account keys.
